# Frontend OSINT Graph Web

Ce dossier contient l'interface React et la visualisation Cytoscape de la
version web. Le point d'entrée est [src/main.jsx](src/main.jsx) ; la connexion,
la bibliothèque de graphes et le studio sont gérés dans [src/App.jsx](src/App.jsx).
